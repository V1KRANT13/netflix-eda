# Netflix Movies & TV Shows — Exploratory Data Analysis

## 📌 Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

The goal is to understand Netflix's content library through data cleaning, analysis, and visualization using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

The project explores:

- Movies vs TV Shows distribution
- Content added over the years
- Rating distribution
- Movie duration distribution
- Top Netflix genres
- Movies vs TV Shows added by year
- Countries associated with Netflix content
- Movie vs TV Show genre distribution
- Movie vs TV Show rating distribution
- Content added by month

## 🔍 Key Findings

- Netflix has more Movies than TV Shows in the dataset.
- The number of titles added increased significantly over the years.
- TV-MA is one of the most common ratings.
- Most movies have a duration of approximately 80–120 minutes.
- International Movies is among the most common categories.
- The United States is associated with the largest number of Netflix titles.
- Movies and TV Shows have different genre and rating distributions.
- Netflix adds content throughout the year, with some months having more additions than others.
